# 08 - Computer Networking

> The fundamentals that power every distributed system and interview.

## What It Covers

- **Models**: OSI 7-layer, TCP/IP
- **Transport**: TCP, UDP, HTTP/HTTPS, TLS, SSH, FTP, SMTP
- **Internet**: IP (v4/v6), DNS, DHCP, ARP, ICMP, subnetting, CIDR
- **Infrastructure**: Routing, Switching, VLAN, NAT, VPN, Firewall, Proxy, Reverse Proxy, Load Balancer, CDN

## Sample Interview Questions

1. What happens when you type a URL and press Enter?
2. Explain the difference between TCP and UDP.
3. How does DNS resolution work?
4. Explain the three-way handshake and what happens if a packet is lost.
5. What is a load balancer and which strategies exist?
6. How do you troubleshoot "cannot reach the server"?
7. Explain HTTPS/TLS handshake.

## Prep Tips

- Draw the full OSI/TCP-IP stack and map protocols to layers.
- Be able to narrate the URL journey end-to-end — the most-asked networking question.
- Practice subnetting math.
