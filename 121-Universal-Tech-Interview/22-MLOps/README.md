# 22 - MLOps / LLMOps

> Operationalizing ML and LLM systems: pipelines, deployment, monitoring, and lifecycle.

## What It Covers

- **Core**: ML Lifecycle, CI/CD for ML, Model Registry, Feature Stores, Data/Model Versioning
- **Deployment**: Batch vs Online, Model Serving, GPU Inference, Scaling, A/B Testing
- **Monitoring**: Drift Detection, Performance Monitoring, Retraining, Alerting
- **Ops**: Reproducibility, Governance, Security, Cost Optimization (esp. LLMs)

## Sample Interview Questions

1. What is CI/CD for ML and how is it different from software CI/CD?
2. How do you detect and handle model/data drift?
3. How do you deploy a model for real-time inference at scale?
4. What is a model registry and why do you need one?
5. How do you retrain a model safely?
6. How do you monitor an LLM application in production?
7. Design an end-to-end ML pipeline for a recommendation model.

## Prep Tips

- Know the full lifecycle: data → train → validate → register → deploy → monitor → retrain.
- Understand the ML vs ML Ops split (model building vs model serving).
- For LLMOps: cost, latency, quality, and evaluation are the hot topics.
