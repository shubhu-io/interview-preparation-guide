# 25 - Testing & QA

> Manual and automated testing, defect lifecycle, and quality strategy.

## What It Covers

- **Core**: SDLC/STLC, Test Plan/Strategy/Cases, Test Data, Test Execution, Defect Management
- **Types**: Unit, Integration, System, UAT, Regression, Smoke, Sanity, Performance, Security, Mobile Testing
- **Automation**: Selenium, Playwright, Cypress, Appium, pytest, Postman, API Testing
- **Practice**: Test Design (BVA, Equivalence), Bug Lifecycle, Severity vs Priority

## Sample Interview Questions

1. What is the difference between smoke and regression testing?
2. How do you write a good test case? Give examples.
3. Manual vs automated testing — when do you automate?
4. Explain the bug lifecycle.
5. What is the difference between severity and priority?
6. How do you automate an end-to-end login flow?
7. How do you test an API without a UI?

## Prep Tips

- Know the STLC phases and when each test type runs.
- Practice writing test cases with positive, negative, and boundary conditions.
- Build one automation framework (e.g., Playwright) for a demo project.
