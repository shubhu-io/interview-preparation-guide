# 29 - Game Development

> Building interactive experiences: engines, physics, rendering, and game logic.

## What It Covers

- **Engines**: Unity, Unreal Engine, Godot, Game Engines Concepts
- **Core**: Game Loop, Physics, Rendering, AI, Animation, Audio, Input Handling
- **Logic**: State Machines, Behaviors, Scripting, Data-Driven Design
- **Practice**: Optimization, Mobile Games, Multiplayer Networking

## Sample Interview Questions

1. Explain the game loop (update, render, fixed timestep).
2. How does physics simulation work in a game engine?
3. What is the difference between update and fixed update in Unity?
4. How do you optimize a game's performance (draw calls, LOD)?
5. How do you implement a state machine for an enemy AI?
6. How do you handle networking in a multiplayer game?
7. How do you design the architecture of a small game?

## Prep Tips

- Ship one complete small game (any engine) for your portfolio.
- Understand the game loop and the difference between frame-based and time-based updates.
- Know at least one engine's core workflow in depth.
