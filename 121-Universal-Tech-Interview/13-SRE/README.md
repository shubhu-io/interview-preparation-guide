# 13 - SRE

> Site Reliability Engineering: SLIs, SLOs, error budgets, and production systems at scale.

## What It Covers

- **Core**: SLI, SLO, SLA, Error Budgets
- **Reliability**: Availability, Latency, Capacity Planning, DR
- **Operations**: Incident Management, Postmortems, On-call, Monitoring, Alerting, Observability
- **Practice**: Chaos Engineering, Toil Reduction, Performance Engineering

## Sample Interview Questions

1. What is an error budget and how does it drive decisions?
2. Difference between SLI, SLO, and SLA?
3. An alert fires at 3am — what is your runbook?
4. How do you design alerts that page people only when needed?
5. What is the difference between SRE and DevOps?
6. Explain a blameless postmortem. Why blameless?
7. How do you measure and reduce toil?

## Prep Tips

- Know how to define an SLO and calculate availability (e.g., 99.9% = downtime budget).
- Practice an incident response narrative end-to-end.
- Understand monitoring vs logging vs tracing (observability pillars).
