# 02 - Programming Languages

> Interview depth for every major language: syntax, internals, concurrency, and common questions.

## Languages Covered

C · C++ · Java · Python · JavaScript · TypeScript · C# · Go · Rust · Kotlin · Swift · PHP · Ruby · Dart · Scala · R · MATLAB · Bash · PowerShell · SQL

## Core Topics Per Language

- Syntax, variables, data types, functions
- OOP, collections, error handling
- Memory management & garbage collection
- Concurrency & async programming
- Packages/modules, testing, debugging
- Performance + language-specific internals
- Common interview questions

## Sample Interview Questions

1. **Python**: Explain GIL. How does it affect threading?
2. **Java**: Difference between ArrayList and LinkedList. How does HashMap work?
3. **C++**: What are pointers vs references? Explain RAII.
4. **JS**: Explain closures, hoisting, and the event loop.
5. **Go**: How do goroutines differ from threads?
6. **Rust**: What is ownership and borrowing?
7. **SQL**: (see [07 Database](07-Database/))

## Prep Tips

- Choose 1 primary + 1 secondary language.
- For each language, know its top 3 "gotchas" and concurrency model.
- Write 10 small programs per language to test memory/collection behavior.
