# 28 - Blockchain & Web3

> Distributed ledgers, smart contracts, and decentralized applications.

## What It Covers

- **Core**: Blockchain, Blocks, Hash, Merkle Tree, Consensus (PoW/PoS), Wallets, Keys
- **Web3**: Smart Contracts, Solidity, Ethereum, Tokens (ERC-20/721), DApps, DeFi, DAOs
- **Practice**: Gas Optimization, Security (Reentrancy, Overflow), Audits
- **Tools**: Hardhat, Foundry, MetaMask, IPFS, Testing

## Sample Interview Questions

1. How does a blockchain achieve consensus? PoW vs PoS?
2. What is a hash and how is it used to link blocks?
3. What is a smart contract? Give an example.
4. What are the common smart contract vulnerabilities?
5. Public key vs private key — how do wallets work?
6. What is the difference between ERC-20 and ERC-721?
7. Why is blockchain immutable?

## Prep Tips

- Understand the block structure and how tampering is detected.
- Write and deploy one simple smart contract on a testnet.
- Know the top security exploits: reentrancy, integer overflow, access control.
