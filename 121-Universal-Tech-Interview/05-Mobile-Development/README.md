# 05 - Mobile Development

> Android, iOS, and cross-platform interview preparation.

## What It Covers

- **Android**: Kotlin, Jetpack Compose, Activities/Fragments, ViewModel, Room, WorkManager
- **iOS**: Swift, SwiftUI/UIKit, Combine, Core Data, App Lifecycle
- **Cross-platform**: Flutter, React Native
- **Core**: Mobile APIs, Mobile Security, App Architecture, State Management, Testing, App Deployment

## Sample Interview Questions

1. Explain the Android/iOS app lifecycle.
2. How do you manage state in a large app (MVVM/MVI)?
3. How do you handle offline-first data sync?
4. Compare Flutter vs React Native.
5. How do you manage memory in a mobile app (leaks, large images)?
6. How do you secure tokens and sensitive data on-device?
7. How do you write a smooth scrolling list with pagination?

## Prep Tips

- Build 1 native app + 1 cross-platform app.
- Know lifecycle + architecture + state management cold.
- Be ready to discuss app store submission and CI.
