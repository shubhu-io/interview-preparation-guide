# 10 - Cloud Computing

> AWS, Azure, GCP, and the architecture patterns behind modern infrastructure.

## What It Covers

**AWS**: EC2, S3, IAM, VPC, RDS, DynamoDB, Lambda, ECS, EKS, CloudFront, Route 53, ELB, Auto Scaling, CloudWatch, SQS, SNS, S3, Glacier
**Azure**: VMs, Blob Storage, AKS, Functions, VNet, Azure SQL, App Service
**GCP**: Compute Engine, Cloud Storage, GKE, Cloud Functions, BigQuery, Cloud Run
**Patterns**: IAM, Networking, Security, Cost Optimization, HA/DR, Multi-Region, Serverless, Migration

## Sample Interview Questions

1. Explain IAM and least privilege. Give an example policy.
2. Design a highly available web app on a cloud provider.
3. S3 vs EBS vs EFS — when do you use each?
4. Serverless (Lambda) vs containers (ECS/EKS) — trade-offs?
5. How do you handle secrets and configuration?
6. How do you reduce cloud costs?
7. Explain VPC: subnets, security groups, NAT, VPC peering.

## Prep Tips

- Build one real project on the free tier to speak from experience.
- Know the equivalent service across AWS/Azure/GCP (mapping table).
- Always discuss IAM, networking, HA, and cost in architecture answers.
