# 38 - Technical Documentation

> Writing, diagrams, READMEs, and clear communication — an underrated interview skill.

## What It Covers

- **Core**: READMEs, Design Docs, API Docs, Runbooks, Technical Blogs, Doc-as-Code
- **Diagrams**: Architecture Diagrams, Sequence Diagrams, ERD, Flowcharts (Mermaid, PlantUML, Draw.io)
- **Practice**: Documenting a Project, Writing for Engineers vs Non-Technical Users, Versioning Docs
- **Quality**: Clarity, Structure, Audience, Style Guides (Google/Microsoft), Markdown

## Sample Interview Questions

1. How do you write a great README?
2. Write an architecture diagram for your project and explain it.
3. How do you document an API?
4. What belongs in a design doc?
5. How do you make complex concepts simple to explain?
6. How do you document a system you inherited?
7. What is your approach to writing technical articles?

## Prep Tips

- Write a README + design doc + architecture diagram for your main project.
- Practice explaining your project with a diagram in 5 minutes.
- Know the doc templates: design doc, ADR, runbook, onboarding doc.
