# 21 - Agentic AI

> AI agents that use tools, plan, and act — the frontier of applied GenAI.

## What It Covers

- **Core**: Agent Architecture, Agent Loop (perceive → reason → act), Tool Calling, Planning
- **Patterns**: ReAct, Function Calling, Multi-Agent Orchestration, Reflection
- **Memory**: Short-term, Long-term, Vector Memory, Conversation Memory
- **Practice**: Agent Eval, Guardrails, Error Handling, Cost Control, Observability

## Sample Interview Questions

1. What is an AI agent and how does it differ from a plain LLM call?
2. How does tool calling work and why does it matter?
3. Design an agent that books a flight with multiple tools and fallbacks.
4. How do you give an agent long-term memory?
5. Multi-agent vs single agent — when do you use each?
6. How do you evaluate an agent reliably?
7. What are the safety/security risks of autonomous agents?

## Prep Tips

- Build one agent end-to-end (e.g., a customer-support agent with tools + memory).
- Know the ReAct pattern and how LLMs call functions/APIs.
- Always discuss failure handling: retries, timeouts, human-in-the-loop, guardrails.
