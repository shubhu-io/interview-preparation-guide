# 27 - Robotics

> The intersection of hardware, software, and AI for autonomous machines.

## What It Covers

- **Core**: Sensors (LiDAR, cameras, IMU), Actuators, Control Systems, ROS
- **Algorithms**: SLAM, Path Planning (A*, RRT), Localization (Kalman, Particle), PID Control
- **Practice**: Simulation (Gazebo, Webots), Computer Vision, Embedded Integration
- **Applications**: Mobile Robots, Drones, Manipulators, Warehouse Automation

## Sample Interview Questions

1. What is ROS? Topics, services, and actions?
2. Explain SLAM and why localization matters.
3. How does a PID controller work? How do you tune it?
4. Kalman filter vs particle filter — when do you use each?
5. How do you fuse data from multiple sensors?
6. What is the difference between local and global path planning?
7. Design a robot that navigates a warehouse autonomously.

## Prep Tips

- Learn ROS fundamentals with a simulation (turtlesim → Gazebo).
- Know the robot software stack: perception → localization → planning → control.
- Be ready for kinematics, sensor math, and control theory questions.
