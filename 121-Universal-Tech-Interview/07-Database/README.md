# 07 - Database

> SQL + NoSQL fundamentals, transactions, indexing, and scaling.

## What It Covers

**SQL**: MySQL, PostgreSQL, Oracle, SQL Server, MariaDB
**NoSQL**: MongoDB, Redis, Cassandra, DynamoDB, Couchbase, Neo4j
**Concepts**: CRUD, Joins, Subqueries, CTE, Window Functions, Indexes, Transactions, ACID, Isolation Levels, Normalization/Denormalization, Replication, Sharding, Partitioning, Query Optimization, Backup/Recovery, High Availability

## Sample Interview Questions

1. What is the difference between INNER, LEFT, RIGHT, and FULL JOIN?
2. Explain ACID properties with a real banking example.
3. What is an index and when does it hurt more than help?
4. Normalization vs denormalization — when do you denormalize?
5. How do you design a system to scale writes (sharding)?
6. Explain read replicas and how they keep data consistent.
7. SQL vs NoSQL — how do you choose?

## Prep Tips

- Write queries by hand daily (joins, window functions, group by).
- Know isolation levels and their anomalies (dirty read, lost update).
- Be ready to design a schema for a small system on a whiteboard.
