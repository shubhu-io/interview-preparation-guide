# 11 - DevOps

> CI/CD, containers, orchestration, infrastructure as code, and SRE fundamentals.

## What It Covers

**CI/CD**: Git, GitHub Actions, GitLab CI, Jenkins, ArgoCD, Release Management
**Containers**: Docker, Docker Compose, Image optimization, Registry
**Orchestration**: Kubernetes, Helm, Service Mesh
**IaC**: Terraform, Ansible, CloudFormation, Pulumi
**Operations**: Monitoring, Logging, Alerting, Secrets, Environment Management

## Sample Interview Questions

1. What is the difference between CI and CD? Walk through a pipeline.
2. How does Docker differ from a VM?
3. Explain Kubernetes pods, deployments, and services.
4. What is Infrastructure as Code and why does it matter?
5. How do you handle secrets in CI/CD pipelines?
6. Blue-green vs canary vs rolling deployment — compare.
7. How do you roll back a failed release?

## Prep Tips

- Build one complete pipeline: code → test → build image → deploy.
- Know the deployment strategy trade-offs (downtime, risk, cost).
- Understand the difference between Dockerfile vs Compose vs Kubernetes.
