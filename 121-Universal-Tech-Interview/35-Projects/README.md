# 35 - Projects

> Turning projects into interview wins: building, documenting, and defending them.

## What It Covers

- **Core**: Choosing Projects, Project Management, Tech Stack Selection, Learning by Building
- **Quality**: Clean Code, Testing, Documentation, Architecture, Git History
- **Defense**: Explaining Your Project, Trade-offs, Challenges, Results
- **Showcase**: GitHub Portfolio, Demos, Metrics, Writeups

## Sample Interview Questions

1. Tell me about your best project. What problem did it solve?
2. Why did you choose that tech stack?
3. What was the hardest bug you fixed in that project?
4. What would you do differently if you rebuilt it?
5. How did you measure success?
6. What is the bottleneck in your system?
7. How did you handle collaboration/version control?

## Prep Tips

- Have 2-3 projects with clear stories: problem → approach → result → lessons.
- Know every line of code and every trade-off in your projects.
- Quantify impact: users, requests, latency, cost savings, or performance gains.
