# 37 - System Design (Deep Dive)

> Low-level design and implementation-heavy system design: machine coding, OOP, and LLD.

## What It Covers

- **Core**: Object-Oriented Design, SOLID, Design Patterns (Factory, Strategy, Observer, Singleton), UML, Class Design
- **Problems**: Design a Library, Parking Lot, Elevator, ATM, Vending Machine, Chess, Social Network (LLD)
- **Practices**: Machine Coding Rounds, Code Structure, Testing, Time Management
- **Concepts**: Coupling/Cohesion, Abstraction, Dependency Injection, Interfaces

## Sample Interview Questions

1. Design a parking lot system (classes, relationships).
2. Design a library management system with SOLID.
3. Design a chess game with clean extensible design.
4. Explain the Strategy pattern with a real example.
5. How do you approach a machine coding round in 90 minutes?
6. Design an e-commerce cart with discount rules.
7. When do you use composition over inheritance?

## Prep Tips

- Practice 5-10 LLD problems: define requirements → classes → relationships → methods → tests.
- Know SOLID and the common design patterns with examples.
- In machine coding: plan before coding, structure classes cleanly, write tests.
