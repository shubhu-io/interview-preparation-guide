# 19 - Machine Learning

> Core ML: algorithms, training, evaluation, and the hands-on skills interviewers probe.

## What It Covers

- **Core**: Supervised/Unsupervised/RL, Regression, Classification, Clustering, Feature Engineering
- **Algorithms**: Linear/Logistic Regression, Decision Trees, Random Forest, XGBoost, SVM, K-Means, KNN, Naive Bayes, Neural Networks
- **Practice**: Train/Test Split, Cross-Validation, Overfitting, Regularization (L1/L2), Hyperparameter Tuning, Evaluation Metrics
- **Tools**: scikit-learn, pandas, NumPy, matplotlib

## Sample Interview Questions

1. Explain the bias-variance trade-off.
2. How does gradient descent work? What is a learning rate?
3. What is regularization and why does it help?
4. How do you choose between a decision tree and a random forest?
5. Explain cross-validation. Why use it?
6. How do you evaluate an imbalanced classification model?
7. Feature engineering vs feature selection — what's the difference?

## Prep Tips

- Implement core algorithms from scratch once (regression, KNN, logistic).
- Know the evaluation metrics for each problem type (accuracy, precision, recall, F1, AUC).
- For every algorithm: intuition, math, hyperparameters, pros/cons, when to use.
