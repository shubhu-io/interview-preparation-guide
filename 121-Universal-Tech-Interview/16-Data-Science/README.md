# 16 - Data Science

> Statistics, machine learning, and experimentation to extract insight and predict outcomes.

## What It Covers

- **Core**: Statistics, Probability, Linear Algebra, Python (NumPy, pandas, matplotlib)
- **ML**: Supervised/Unsupervised Learning, Model Selection, Evaluation, Overfitting
- **Practice**: Feature Engineering, A/B Testing, Experimentation, Causal Inference, Storytelling

## Sample Interview Questions

1. Explain the bias-variance trade-off.
2. How do you handle imbalanced classes?
3. Explain p-value, confidence interval, and statistical significance.
4. Design an A/B test. What could go wrong?
5. How do you detect overfitting and fix it?
6. What metrics would you use for a classification problem?
7. How would you predict customer churn end-to-end?

## Prep Tips

- Back every answer with math + intuition, not just vocabulary.
- Complete one end-to-end project (EDA → model → evaluation → insight).
- Practice A/B test design: hypothesis, sample size, metrics, pitfalls.
