# 15 - Data Analytics

> Turning data into decisions: SQL, Excel, visualization, and BI tools.

## What It Covers

- **Tools**: Excel (Advanced, Pivot, Power Query), SQL, Power BI, Tableau, Looker, Python (pandas)
- **Core**: Data Cleaning, Data Visualization, Dashboarding, KPIs, Business Metrics
- **Analysis**: A/B Analysis, Cohort, Funnel, Retention, Revenue Analysis, Reporting

## Sample Interview Questions

1. Write a query to compute month-over-month revenue growth.
2. How would you analyze a drop in signups?
3. What KPIs would you track for an e-commerce business?
4. How do you clean a messy dataset?
5. Design a dashboard for a sales team.
6. Difference between a metric and a KPI?
7. How do you handle null values in a report?

## Prep Tips

- Master SQL aggregation and window functions — the #1 analytics skill.
- Build 2-3 dashboards end-to-end for your portfolio.
- Practice "analyst-style" thinking: state the question → data → insight → recommendation.
