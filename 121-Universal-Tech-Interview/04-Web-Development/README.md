# 04 - Web Development

> Frontend, backend, and the HTTP/auth concepts that glue them together.

## What It Covers

**Frontend**: HTML, CSS, JavaScript, TypeScript, React, Angular, Vue, Next.js, Svelte
**Backend**: Node.js, Express, Java/Spring/Spring Boot, Python/Django/Flask/FastAPI, C#/.NET, PHP/Laravel, Go, Rust
**Concepts**: HTTP/HTTPS, DNS, Cookies, Sessions, CORS, CSRF, XSS, Auth (JWT, OAuth), WebSockets, WebRTC, SSR/CSR/SSG, SPA, PWA

## Sample Interview Questions

1. What happens when you type a URL in the browser?
2. Explain the difference between cookies and sessions.
3. What is CORS and how do you solve it?
4. Explain JWT flow vs session-based auth.
5. What is the difference between SPA and SSR?
6. How do you prevent XSS and CSRF?
7. Explain how WebSockets work vs HTTP polling.

## Prep Tips

- Draw the full request lifecycle from browser to DB.
- Know auth deeply — it appears in every web interview.
- Build one full-stack app end-to-end to anchor the concepts.
