# 33 - Technical Tools

> The everyday tools every engineer must master regardless of role.

## What It Covers

- **Version Control**: Git (branching, rebase, cherry-pick, revert, git workflows)
- **CLI & Shell**: Bash/PowerShell, Linux commands, Terminal productivity
- **Debugging**: Debuggers (gdb, Chrome DevTools), Profiling, Logs, Tracing
- **Productivity**: IDEs, Editors, Docker Desktop, Postman, Jira, Slack, Mermaid, Regex, Markdown

## Sample Interview Questions

1. Explain git merge vs rebase. When do you use each?
2. How do you undo a commit that was already pushed?
3. How do you resolve a merge conflict?
4. How do you debug a production bug with only logs?
5. What is your daily development workflow?
6. How do you find the root cause of a slow query or slow page?
7. What CLI commands do you use daily and why?

## Prep Tips

- Master git: stash, rebase, reflog, cherry-pick — practice the undo commands.
- Be fluent in your shell: aliases, pipes, grep, find.
- For every tool, ask: "what problem does this solve and when would I use it?"
