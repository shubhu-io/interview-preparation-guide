# 26 - Embedded & IoT

> Firmware, microcontrollers, real-time systems, and connected devices.

## What It Covers

- **Core**: C (pointers, memory, bit manipulation), C++, Microcontrollers (AVR, STM32, ESP32), Arduino, Raspberry Pi, Sensors, Actuators
- **Systems**: RTOS (FreeRTOS), ISR, Interrupts, Timers, DMA, Memory-Mapped I/O
- **IoT**: MQTT, CoAP, Protocols, Edge Computing, Power Management, OTA
- **Hardware**: Schematic Reading, Datasheets, SPI/I2C/UART, GPIO

## Sample Interview Questions

1. What is the difference between a process and an RTOS task?
2. How does an interrupt work? What is an ISR and why must it be short?
3. Explain volatile in C and when to use it.
4. What is the difference between I2C, SPI, and UART?
5. How do you manage power in a battery-operated IoT device?
6. Explain memory-mapped I/O vs port I/O.
7. How do you debounce a button in firmware?

## Prep Tips

- Know C deeply: pointers, memory layout, volatile, bitwise ops.
- Build one real project (ESP32/STM32): sensor + display + wireless.
- Understand the RTOS primitives: semaphore, mutex, queue, task priorities.
