# 06 - Data Structures & Algorithms

> The DSA pattern bank that covers ~90% of coding interview problems.

## What It Covers

- **Arrays & Strings**: two pointers, sliding window, prefix sums
- **Linked Lists**: reversal, cycle detection, merge patterns
- **Trees**: traversals, BST, path problems, trie
- **Heaps & Priority Queues**: top-K, merging, scheduling
- **Graphs**: BFS/DFS, shortest path, union-find, topological sort
- **Dynamic Programming**: 1D/2D, knapsack, LIS/LCS, matrix, state machine
- **Others**: binary search, backtracking, greedy, bit manipulation, monotonic stack

## Sample Interview Questions

1. Two Sum (and its follow-ups).
2. Merge two sorted linked lists.
3. Find the longest substring without repeating characters.
4. Detect cycle in a graph.
5. Climbing stairs / house robber (DP intro).
6. K most frequent elements (heap).
7. Word search (backtracking).

## Prep Tips

- 1 pattern/day for 8 weeks beats 100 random problems.
- Always state time & space complexity.
- Practice on a whiteboard AND in a live editor.
