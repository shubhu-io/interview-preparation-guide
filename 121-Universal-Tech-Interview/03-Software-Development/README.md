# 03 - Software Development

> How software is actually built: process, discipline, and engineering principles.

## What It Covers

- **SDLC**: Waterfall, Agile, Scrum, Kanban
- **Process**: Requirements, design, development, testing, deployment, maintenance
- **Engineering**: Clean Code, SOLID, Design Patterns, Refactoring
- **Collaboration**: Code Review, Version Control, Documentation
- **Quality**: Testing strategy, CI, technical debt

## Sample Interview Questions

1. What is the difference between Agile and Waterfall?
2. Explain SOLID principles with a real example.
3. What is a design pattern? Name 3 and when you'd use them.
4. How do you handle technical debt?
5. What does a good code review look like?
6. Explain the difference between a sprint and a release.
7. How would you refactor a god class?

## Prep Tips

- Be able to give one real example per design pattern and SOLID principle.
- Know Scrum ceremonies and roles cold.
- Practice describing your own project's SDLC journey.
