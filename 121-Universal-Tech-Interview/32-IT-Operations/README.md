# 32 - IT Operations

> IT support, NOC, system administration, and keeping infrastructure running.

## What It Covers

- **Core**: ITIL, Service Desk, Incident/Problem/Change/Request Management, SLAs
- **Support**: Tier 1/2/3, Troubleshooting, Ticketing (ServiceNow, Jira), Remote Support
- **Admin**: Windows/Linux administration, Active Directory, Networking, Backups, Patching
- **Practice**: Monitoring, Documentation, Runbooks, On-call

## Sample Interview Questions

1. What is the difference between an incident and a problem?
2. Walk me through your troubleshooting process for a server down.
3. How do you prioritize tickets when everything is urgent?
4. What is a change management process and why is it needed?
5. How do you handle a user with a login issue?
6. What do you monitor in a production environment?
7. Explain the ITIL service lifecycle stages.

## Prep Tips

- Know ITIL core processes: incident, problem, change, request, service asset.
- Practice structured troubleshooting (isolate → root cause → fix → verify → document).
- Be comfortable with AD, DNS, DHCP, and basic Linux commands.
