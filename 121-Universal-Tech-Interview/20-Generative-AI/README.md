# 20 - Generative AI / LLM

> LLMs, transformers, RAG, fine-tuning, agents, and the GenAI engineering stack.

## What It Covers

- **Core**: Transformers, Attention, Tokens, Embeddings, Context Windows, Prompt Engineering
- **Techniques**: RAG, Fine-Tuning, LoRA, Function Calling, Tool Use, Structured Outputs
- **Systems**: Vector Databases, LLM Gateways, Eval Harness, Guardrails, Hallucination Mitigation
- **Ops**: LLM Ops, Cost/Latency, Observability, Safety/Alignment

## Sample Interview Questions

1. Explain the Transformer architecture and self-attention.
2. What is RAG? When do you use it vs fine-tuning?
3. What are embeddings and how are they used?
4. How do you reduce hallucinations in an LLM app?
5. What is LoRA and why is it efficient?
6. How do you evaluate an LLM system?
7. How would you build a chat-over-your-docs application?

## Prep Tips

- Build one RAG app end-to-end (ingestion, embeddings, retrieval, generation, eval).
- Know the transformer internals: Q/K/V, positional encoding, tokens.
- Be able to compare RAG vs fine-tuning vs prompt engineering with trade-offs.
