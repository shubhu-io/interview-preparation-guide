# 01 - Computer Science Fundamentals

> The core CS foundation every technical interview builds on.

## What It Covers

- **Data Structures**: Arrays, Strings, Linked Lists, Stack, Queue, Deque, Hash Tables, Trees, Binary Trees, BST, AVL, Heaps, Priority Queues, Trie, Graphs, Disjoint Set / Union-Find
- **Algorithms**: Searching, Sorting, Recursion, Backtracking, Greedy, Dynamic Programming, Divide & Conquer, Sliding Window, Two Pointers, Binary Search, BFS/DFS, Shortest Path, MST, Topological Sort, Bit Manipulation
- **CS Fundamentals**: OOP, Operating Systems, DBMS, Computer Networks, Computer Architecture, Digital Logic, Compiler Design, Theory of Computation, Distributed Systems, Concurrency, Parallelism, Complexity Analysis

## Sample Interview Questions

1. Explain time complexity. What is Big-O, Big-Theta, Big-Omega?
2. Difference between stack and queue, and a real use case for each.
3. How would you detect a cycle in a linked list?
4. Explain the difference between process and thread.
5. What is the difference between `==` and `equals()` (Java) / `is` and `==` (Python)?
6. Explain deadlock and the four necessary conditions.
7. What happens during a context switch?

## Prep Tips

- Master recursion → backtracking → DP in that order.
- Practice 1 DSA pattern/day for 8 weeks.
- Always state time & space complexity when answering.
