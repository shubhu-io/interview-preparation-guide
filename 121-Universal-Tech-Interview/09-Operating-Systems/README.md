# 09 - Operating Systems

> Processes, threads, memory, and concurrency — the core OS interview topics.

## What It Covers

- **Processes & Threads**: states, context switch, scheduling, IPC
- **Concurrency**: Mutex, Semaphore, Deadlock, Race Condition, Starvation, Atomicity
- **Memory**: Virtual Memory, Paging, Segmentation, TLB, Page Fault, Cache, Swapping
- **File Systems**: inodes, permissions, disk scheduling

## Sample Interview Questions

1. Difference between process and thread?
2. Explain deadlock and the 4 necessary conditions. How do you prevent it?
3. What is a race condition? How do you solve it (lock, atomic, mutex)?
4. Explain virtual memory and paging.
5. Mutex vs semaphore?
6. What is context switching and when does it happen?
7. How do processes communicate (shared memory, message passing, pipes)?

## Prep Tips

- Know the process/thread lifecycle state diagram by heart.
- Practice deadlock + race condition problems until fluent.
- Connect each OS concept to real code (threads, locks, memory).
