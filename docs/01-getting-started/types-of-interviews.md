# Types of Interviews

A reference for every interview format you may encounter, what it tests, and where to prepare.

## Interview Types at a Glance

| Type | Purpose | Format | Typical Duration |
|------|---------|--------|------------------|
| Phone / Video Screen | Verify basics, salary, availability | Recruiter call | 15-30 min |
| Online Assessment (OA) | Aptitude + coding + domain MCQs | Timed proctored platform | 1-4 hours |
| Technical Interview | Depth in your domain | 1-2 rounds, whiteboard/IDE | 45-60 min each |
| Live Coding | Code under observation, explain thinking | Shared editor | 45-60 min |
| Machine Coding | Build a working feature/app | IDE, longer window | 1.5-3 hours |
| Take-Home Assignment | Asynchronous full problem | Submit within days | 1-7 days |
| System Design (HLD) | Architect scalable systems | Whiteboard / diagram tool | 45-60 min |
| Low-Level Design (LLD) | OOP + class design | Whiteboard | 45-60 min |
| Whiteboard / Puzzle | Problem-solving process | Marker + board | 30-45 min |
| Domain / Specialization | Depth in VLSI, IoT, AI, etc. | Q&A + design | 45-60 min |
| Panel Interview | Multiple interviewers, consensus | Several people | 60-90 min |
| Bar Raiser | Hiring-bar protection | Behavioral + technical | 45-60 min |
| Managerial / HM | Team fit, mentorship, strategy | 1-1 with manager | 45-60 min |
| Behavioral / HR | STAR stories, culture, compensation | 1-1 | 30-45 min |
| Case Interview | Business/strategy problem | Structured Q&A | 30-45 min |
| Group Discussion | Team dynamics & articulation | With other candidates | 20-40 min |

## Universal Success Frameworks

### For Technical Questions
1. **Clarify** — restate the problem, ask edge-case questions.
2. **Think out loud** — narrate your reasoning.
3. **Brute force first** — then optimize with time/space trade-offs.
4. **Code cleanly** — meaningful names, no syntax heroics.
5. **Test** — walk through examples and edge cases.
6. **Summarize** — complexity analysis and what you'd improve.

### For Behavioral Questions (STAR)
See [STAR Method](../../87-STAR-Method/) — Situation, Task, Action, Result.

### For Design Questions
1. Requirements → 2. Estimation → 3. Data model/API → 4. High-level diagram → 5. Deep dive → 6. Trade-offs.
