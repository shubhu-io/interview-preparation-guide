## Tips for Direct Applications

1. Create a single account per company and save a master profile.
2. Set email alerts for target roles on each career page.
3. Check the "campus/early career" or "freshers" section for entry roles.
4. Apply within 48 hours of posting.
5. Track every application in a spreadsheet (see [Job Search Strategy](job-search-strategy)).
