# 121 - Universal Technical Interview Preparation AI

> A 38-domain master system for preparing for technical interviews across software, IT, cloud, data, AI, cybersecurity, infrastructure, and engineering. Use the master prompt with any AI to get a personalized interview coach, or study each domain folder directly.

---

## Quick Start

1. Read the [Master Prompt](../../121-Universal-Tech-Interview/master-prompt/).
2. Copy-paste the entire prompt into your favorite AI (ChatGPT, Claude, Gemini).
3. Say **START** to begin a diagnostic interview, or provide your **Job Description**, **Resume**, or **Project** and it will adapt.
4. Study each domain folder here for structured notes, sample questions, and links to the repo's detailed folders.

## How the Master Prompt Works

| Feature | What It Does |
|---------|--------------|
| Role Detection | Infers your target role from JD/resume/title |
| 31 Interview Stages | Resume screen → OA → DSA → system design → offer |
| 44 Domains of Questions | Any technology, any depth |
| Mock Modes | Quick (10), Standard (20), Full (40-60), Rapid Fire |
| Evaluation | Scores each answer X/10 with corrections |
| Weakness Tracking | Retests what you fail |
| Debugging Mode | Realistic production incidents, progressive hints |
| Company Prep | Research-backed company-specific guidance |
| Scorecards | Final 7-day plan with readiness % |
