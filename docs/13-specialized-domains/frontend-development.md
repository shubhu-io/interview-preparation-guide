# Frontend Development

## Introduction

Frontend developers build the user-facing layer of web apps — the UI, interactivity, performance, and accessibility. Roles: Frontend Developer, UI Engineer, React/Vue/Angular Developer, Web Performance Engineer.

## What the Role Does

- Build responsive interfaces with HTML, CSS, JavaScript/TypeScript.
- Work in frameworks: React, Vue, Angular, Svelte.
- Manage state (Redux, Zustand), routing, and API integration.
- Ensure performance (Core Web Vitals), accessibility (a11y), and SEO.
- Test UI (Jest, Testing Library, Cypress) and bundle/building tools (Vite, Webpack).

## Hiring Companies

All web product companies and startups. Strong frontend teams: Meta, Google, Netflix, Airbnb, Stripe, Atlassian, Shopify, Zomato, Swiggy, CRED, Meesho, Flipkart.

## Core Topics

| Topic | What to Know |
|-------|--------------|
| HTML/CSS | Semantic HTML, Flexbox/Grid, responsive design, animations |
| JavaScript/TS | ES6+, closures, promises, async/await, DOM, modules ([29-JavaScript](../../29-JavaScript/)) |
| React | Components, hooks, props/state, context, rendering, memo |
| State Management | Redux, Zustand, React Query/SWR |
| Data Fetching | REST, GraphQL, caching, optimistic updates |
| Performance | Core Web Vitals, lazy loading, code splitting, bundle size |
| Accessibility | ARIA, semantic structure, keyboard nav |
| Build Tooling | Vite, Webpack, Babel, npm/yarn/pnpm |
| Testing | Jest, Vitest, Testing Library, Cypress/Playwright |
| CSS Solutions | Tailwind, CSS-in-JS, styled-components, MUI |

## Interview Roadmap (12 Weeks)

```
Weeks 1-2:   HTML/CSS/JS fundamentals + DOM practice
Weeks 3-4:   ES6+ deep dive + mini projects
Weeks 5-6:   React: components, hooks, state (build a real app)
Weeks 7-8:   Data fetching, state management, routing
Weeks 9-10:  Performance + accessibility + build tooling
Weeks 11-12: Mock coding rounds + polished portfolio site
```

## Sample Interview Questions

- What happens when you type a URL and press Enter?
- Explain closures and event delegation in JavaScript.
- How do you optimize a React app that re-renders too often? (memo, useMemo, key, code splitting)
- Explain the difference between `==` vs `===`, and how JavaScript handles hoisting.
- How would you make a score from Core Web Vitals better?
- Write a debounce function. Write a custom React hook.
- How do you handle accessibility in a modal dialog?

## Projects for Portfolio

- A full React app with auth, API integration, routing, and responsive design.
- A component library with variants, docs, and tests.
- A real-time dashboard with charts and WebSocket updates.
- A portfolio site with 90+ Lighthouse performance score.

## Tools to Learn

- Frameworks: React (primary), Vue, Angular, Svelte
- Language: TypeScript
- Build: Vite, Webpack, Next.js (SSR/SSG)
- Styling: Tailwind, MUI, styled-components
- Testing: Jest/Vitest, Testing Library, Playwright

## Common Mistakes

1. Knowing framework features but weak vanilla JS fundamentals.
2. Ignoring performance and accessibility — both are asked in senior rounds.
3. No testing story (Jest/Playwright) in the portfolio.
4. Not understanding the rendering cycle (re-renders, memoization).
5. Building one app but not being able to explain its architecture decisions.
