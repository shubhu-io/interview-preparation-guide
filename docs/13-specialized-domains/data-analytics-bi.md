# Data Analytics & Business Intelligence (BI)

## Introduction

Data analysts turn raw data into decisions. They build dashboards, run analyses, and answer business questions. Roles: Data Analyst, Business Analyst, BI Analyst, MIS Analyst, Reporting Analyst, Power BI/Tableau Developer.

## What the Role Does

- Write SQL to extract and explore data from warehouses.
- Build dashboards in Power BI, Tableau, Looker, Excel.
- Run funnel, cohort, and regression analyses.
- Automate recurring reports and alerting.
- Communicate insights to non-technical stakeholders.

## Hiring Companies

Every company has analytics teams. Finance, retail, e-commerce, telecom, healthcare, and tech: Flipkart, Myntra, PhonePe, Swiggy, Zomato, Deloitte, KPMG, Accenture, Fractal, Mu Sigma.

## Interview Roadmap (12 Weeks)

```
Weeks 1-2:   Advanced SQL mastery (window functions, multi-step queries)
Weeks 3-4:   Excel deep dive: Power Query, pivot tables, formulas
Weeks 5-6:   Power BI/Tableau: data model, DAX, compelling dashboards
Weeks 7-8:   Statistics for business + metric definitions
Weeks 9-10:  Case studies: retention, revenue, A/B analysis
Weeks 11-12: Portfolio dashboards + mock case interviews
```

## Sample Interview Questions

- Write SQL to compute month-over-month revenue growth per region.
- Revenue dropped 8% in one week. How would you investigate?
- Build a dashboard for a sales team. What charts and metrics would you include?
- Calculate and explain LTV/CAC. What does a healthy ratio look like?
- How do you handle dirty data (nulls, duplicates, outliers)?
- Explain a DAX measure that computes running total.
- How do you present a bad-news analysis to leadership?

## Projects for Portfolio

- A polished Power BI/Tableau dashboard on a public dataset with a narrative.
- A SQL deep-dive (e.g., 20-question analysis) with documented insights.
- An Excel model: profitability, forecasting, scenario analysis.
- A written "insight memo" for a business question backed by data.

## Tools to Learn

- SQL: BigQuery, Postgres, MySQL, DuckDB
- BI: Power BI (free desktop), Tableau Public, Looker Studio
- Excel: Power Query, XLOOKUP, pivot tables, charts
- Python optional: pandas, matplotlib, seaborn

## Common Mistakes

1. Dashboards that are pretty but don't answer a business question.
2. Weak SQL basics under interview pressure.
3. Ignoring metrics — the interview is about decisions, not charts.
4. Presenting analysis without a recommendation.
5. Not knowing your own dashboard model/DAX inside out.
